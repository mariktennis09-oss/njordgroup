# Фотографии для замены заглушек

Реальных фотографий у заказчика на момент разработки не было. Все изображения
ниже — временные градиентные SVG-заглушки в фирменной палитре
(`public/images/*.svg`), с подписью прямо на картинке, что должно быть в кадре.
Это техническое задание для фотографа/фотобанка. Названия файлов менять не
нужно — просто заменить содержимое файла на реальное фото с тем же именем
(расширение можно сменить на `.jpg`/`.webp`, тогда поправить импорт в
соответствующем компоненте/контенте на новое расширение).

## Open Graph превью

Отдельного файла не требуется: превью для соцсетей и мессенджеров
генерируется кодом в настоящий PNG 1200×630 на этапе сборки —
`src/app/opengraph-image.tsx`. Чтобы поменять текст или фон превью, править
этот файл, а не картинку. Проверить результат: `/opengraph-image`.

## Логотип

Логотип — не растровый файл, а inline SVG-компонент `components/layout/Logo.tsx`
(текстовый леттеринг «NJORD GROUP» + знак-волна), с вариантами `dark` и `light`
через проп `variant`. Если у компании появится готовый логотип в векторе,
заменить разметку внутри `Logo.tsx` на реальный SVG-путь, сохранив тот же API
компонента (`variant`, `className`).

Favicon — `src/app/icon.svg` (конвенция Next.js, подхватывается автоматически).
Если появится готовый логотип, обновить и его.

## Как понять, что фото ещё не заменено

На каждой заглушке есть подпись «ЗАГЛУШКА — ТРЕБУЕТСЯ ФОТО» — это единственный
маркер, следить за ним при приёмке сайта перед публикацией.
